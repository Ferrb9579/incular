# Incular docs

The docs directory intentionally has only two Markdown files:

- [ARCHITECTURE.md](ARCHITECTURE.md) — the current ownership, dependency, API
  class, lifetime, and backend rules.
- **README.md** — this index.

For public API design rules see `../API_DESIGN.md`. For repository workflow see
`../AGENTS.md`. The machine-checked package graph is
`../specs/architecture.json`.

Historical plans, audits, and completion reports are kept in Git history instead
of active docs.
