# Dependency maintenance and provenance

`dependency-inventory.json` is generated by `python scripts/release.py inventory`
from the locked graph with all features/targets. It lists package identity,
declared license, repository and source. It is not a legal clearance or a full
SBOM for an individual application's selected platform/features.

## ttf-parser maintenance advisory

Owner: Incular rendering/desktop maintainers. Revisit before each release and
on dependency updates. RUSTSEC-2026-0192 identifies `ttf-parser` as unmaintained,
not a specific vulnerability with a patched version. Current paths include
`fontdue -> ttf-parser` in the renderer and `ab_glyph -> owned_ttf_parser ->
ttf-parser` through Winit's Linux decoration stack.

Keep the advisory visible (`cargo deny check -W unmaintained`); no ignore entry
is added. Do not casually replace text rasterization immediately before release:
fontdue behavior, glyph metrics, atlas caching and visual regressions need review.
Evaluate a maintained rasterization path and track upstream Winit/decoration
changes. Treat untrusted font loading as a parser boundary, keep resource limits
and malformed-input tests, and avoid claiming this informational advisory proves
an exploitable defect or that a version bump alone resolves it.

Source: [RustSec RUSTSEC-2026-0192](https://rustsec.org/advisories/RUSTSEC-2026-0192.html).

## Redistribution

Framework archives ship Incular's existing Apache license and their own sources.
Dependencies retain their licenses; downstream binary/source distributions must
meet the obligations of the actual selected dependency graph. No font/image
license may be inferred from Incular's project license. Before adding embedded
assets or externally adapted code, record origin, license, copyright notices and
modifications. Flutter/Material vocabulary in comments does not establish the
provenance of an implementation; maintainers must confirm authorship/adaptation
history before relicensing.

The unresolved Boost/Unlicense policy choices are recorded in [licensing](licensing.md).
