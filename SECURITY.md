# Security policy

Please do not publish an unpatched security vulnerability in a public issue.

Use GitHub's private vulnerability reporting for this repository when it is
available. Include the affected version or commit, platform, reproduction
steps, impact, and any suggested mitigation. If private reporting is not
available, contact the repository maintainers privately through the GitHub
repository before disclosure.

Security fixes should include a regression test where practical. Do not put
credentials, private keys, access tokens, or sensitive user data in reports.
