# Community conduct

Be respectful and specific. Critique code and behavior, not people's identities
or motives. Welcome questions and different experience levels. Harassment,
threats, discriminatory language, doxxing, sexual attention and repeated unwanted
contact are not acceptable in project spaces.

Maintainers may edit/remove harmful content, close discussions, or restrict
participation. Responses should be proportionate, protect people who report
harm, and explain the action where doing so does not expose private information.

The current maintainer is [Ferrb9579](https://github.com/Ferrb9579). For public
moderation requests, use GitHub's report-content controls on the affected content.
For a private conduct complaint, use GitHub's abuse-reporting channel rather
than posting sensitive details in an issue. A dedicated private project conduct
contact must be confirmed before expanding the maintainer/community program;
no unverified email address is advertised here.

Security defects use the separate [security reporting route](SECURITY.md).
